# 隐私协议

**生效日期：2026 年 10 月 13 日**

欢迎使用洛谷档案馆（以下简称"本站"）。本站是一个**第三方、非官方**的洛谷社区内容存档站点，与洛谷（luogu.com.cn）官方无任何隶属或合作关系。

本协议说明本站收集哪些信息、如何使用与保护这些信息，以及您享有的权利。本协议的每一条描述均与本站当前实现相对应。若您不同意本协议，请停止使用本站服务。

## 一、我们收集的信息

### 1. 自动存档的洛谷公开内容

本站通过爬虫从洛谷公开页面抓取并长期保存以下内容。所有被存档内容在洛谷上均为**公开可访问**状态，我们不抓取任何需要越权才能查看的私密内容：

| 内容类型 | 保存的字段 |
| --- | --- |
| 专栏文章 | 文章 ID、作者 UID、标题、正文全文、洛谷管理员备注、逐版本历史 |
| 剪贴板 | 剪贴板 ID、作者 UID、正文全文、逐版本历史 |
| 讨论区帖子（非题目版块） | 帖子 ID、作者 UID、版块、标题、正文 |
| 犇犇 | 犇犇 ID、作者 UID、类型、发布时间、正文 |
| 陶片放逐记录 | 被放逐用户 UID、放逐发生时刻的用户名快照、放逐理由全文、权限增减、时间 |
| 题目公开信息 | 题目编号、标题、难度、标签、题解开放状态 |
| 用户主页 | UID、用户名、头像、背景图、个性签名、徽章、个人介绍、名号颜色、管理员/封禁状态、CCF/ICPC 评级、关注数、粉丝数、通过题数、提交题数、注册时间 |
| 用户历史序列 | 用户名历史版本、个人介绍历史版本、字段变更日志、获奖记录、Elo/咕值时间序列、365 天活动热力图、粉丝/关注/排名数值时间序列 |

说明：

- 文本类字段（文章、剪贴板、介绍等）逐版本保留，同一内容不重复存储；数值类字段（粉丝数、Elo、咕值等）以时间序列方式保存，用于展示历史变化曲线。
- 用户名历史与陶片放逐记录中的用户名快照属于社区治理相关的公开记录，保存它们是本站存档功能的核心目的之一。
- 爬虫默认**仅在用户明确请求时抓取**（如点击"保存"按钮、访问未收录页面触发补档），主动批量扫描功能默认关闭。

### 2. 站内账号信息

注册成为站内用户时，我们收集：

- **邮箱**（唯一标识，用于验证与联系）；
- **密码**（仅以 Argon2 算法哈希存储，任何人（含管理员）无法读取明文）；
- **昵称**（1-16 字符，公开展示）。

注册需完成**邮箱验证**：验证链接令牌有效期 24 小时，验证成功后即清除。未验证邮箱的账号无法登录。重发验证邮件有频率限制（同邮箱 60 秒冷却、同 IP 每小时 5 次），且响应不泄露邮箱是否已注册。

### 3. 洛谷账号绑定（可选）

您可选择绑定自己的洛谷账号以证明内容所有权（用于数据移除的自动审核方式等）。绑定流程：

1. 本站生成一次性挑战文本（有效期 10 分钟）；
2. 您将其放入一个**公开的洛谷剪贴板**；
3. 本站读取该剪贴板核验后绑定您的洛谷 UID。

核验时剪贴板内容**只读取、不存档**。绑定为一对一关系，一个洛谷 UID 只能绑定一个站内账号。

### 4. 登录会话与安全记录

- **会话表**：登录后保存刷新令牌的 **SHA-256 哈希**（不存明文）、您的 **IP 地址**、**User-Agent**（截断至 500 字符）、创建与过期时间。刷新令牌有效期 **7 天**，访问令牌（JWT）仅存于浏览器内存、有效期 **15 分钟**；退出登录即吊销会话。
- **登录安全记录**：最近登录时间与 IP、连续失败次数；连续 5 次失败后账号临时锁定 15 分钟。
- **限流记录**：为防止滥用，注册、登录、保存、删除申请等接口按 IP 做滑动窗口限流，计数键存于 Redis、随窗口自动过期（TTL 为窗口时长 + 1 秒）。
- **保存按钮审计**：每次点击"保存"会记录 IP、User-Agent、目标类型与编号、处理结果（成功/合并/限流/需验证码/失败），存入数据库供排障与反滥用。

### 5. 题解格式修正

- **本地修正**：纯服务器端格式规范化，不联网、不存储您提交的文本。
- **AI 修正**（仅登录用户可用，每用户每小时最多 5 次）：您提交的**题解全文**会与固定的格式规范提示词一起发送给第三方大模型服务。请求中**不包含**您的账号 ID、邮箱等身份标识。修正结果会自动附加"本题解使用了 [模型] 进行润色"的 AI 参与声明。站内**不保存**提示词与模型响应，但第三方模型提供商自身的留存政策适用于该次传输。

### 6. 插件相关

- 插件上传/更新/删除申请：记录申请人站内账号、申请类型、提交快照与审核结果。
- 插件举报：记录举报人站内账号、举报类型与描述（10-5000 字），限每 IP 每小时 5 次。
- 使用统计（下载/复制计数）：使用 **HMAC-SHA256 不可逆匿名标识**做每日去重（对"日期 + 用户 ID"或"日期 + IP + UA"计算），数据库中**不保存**原始 IP 与 User-Agent。

### 7. 人机验证

注册、触发限流的保存操作等场景需完成人机验证（Turnstile / hCaptcha / 阿里云验证码，视运营配置而定）。验证过程中，第三方验证服务商会收到您的 **IP 地址**与验证令牌，其隐私政策适用于该交互。

### 8. Cookie 与本地存储

| 名称 | 类型 | 用途 | 有效期 |
| --- | --- | --- | --- |
| `la_refresh` | HttpOnly Cookie（Secure、SameSite=Strict，仅限 `/api/v1/auth` 路径） | 登录刷新令牌 | 7 天 |
| `nuxt-color-mode` | localStorage | 深浅色外观偏好 | 长期 |
| `la_logged` | localStorage | "可能已登录"的界面提示标记 | 长期 |
| `quick-jump-type` | localStorage | 首页快捷跳转偏好 | 长期 |

本站**不投放任何广告或第三方追踪 Cookie**。

### 9. 访问统计

本站使用**自建**的 Umami 统计（部署于自有服务器、关闭遥测），仅统计页面浏览量等基础指标。统计脚本对路径做了**脱敏**处理（动态 ID 统一替换为占位符，如 `/article/:id`）。统计不关联站内账号。

### 10. 服务日志

应用运行日志（structlog）输出至服务器标准输出，内容为结构化事件（如抓取失败原因），不主动记录 HTTP 访问日志中的 IP。

## 二、我们如何使用这些信息

1. **存档与展示**：抓取、去重、版本化保存洛谷公开内容，并向公众展示历史快照与变化曲线；
2. **账号服务**：注册登录、邮箱验证、洛谷绑定、关注功能、会话维持；
3. **安全与反滥用**：限流、登录锁定、验证码、保存按钮审计、爬虫熔断与 Cookie 池调度；
4. **内容治理**：处理删除申请、侵权投诉、用户名违规隐藏、插件审核与举报；
5. **服务改进**：基于匿名化统计优化功能与性能；
6. **通知**：向您发送验证邮件、删除申请处理结果；向管理员发送删除申请与系统通知。

我们**不会**将您的个人信息用于个性化广告，**不会**出售您的个人信息。

## 三、信息共享与第三方

仅在以下必要情形下，数据会离开本站服务器：

| 第三方 | 传输内容 | 目的 |
| --- | --- | --- |
| 洛谷（luogu.com.cn / luogu.com） | 爬虫请求（含运营方 Cookie 账号） | 内容抓取、删除申请探测 |
| 大模型提供商（仅在您主动使用 AI 修正时） | 题解全文 + 格式规范提示词 | 题解格式修正 |

除上述情形或法律法规要求外，我们不向任何第三方提供您的个人信息。

## 五、信息安全措施

- 密码使用 **Argon2** 哈希存储，支持透明重哈希；
- 管理员 TOTP 密钥、爬虫 Cookie 使用 **Fernet 对称加密**后入库；
- 会话令牌只存哈希；访问令牌短时效（15 分钟）；Cookie 设置 HttpOnly / Secure / SameSite=Strict；
- 传输层强制 HTTPS（由反向代理终结）；
- 敏感临时数据（限流、挑战、缓存）均带 TTL 自动过期；
- 管理员全部操作留有不可删除的审计日志。

## 六、您的权利

1. **查阅与复制**：您存档内容的当前版本与历史版本均在站内公开可查（文章/剪贴板详情页的"历史版本"时间线）；
2. **更正**：在洛谷上修改后，可点击"保存"按钮或等待访问触发刷新，本站会记录新版本；
3. **删除 / 停止展示**：您可通过[数据移除政策](/policies/data-removal)所述的**自动审核方式**（绑定洛谷账号后申请）要求停止展示您的个人内容，本人申请即时生效；
4. **账号相关**：可随时修改密码；如需注销站内账号，请通过页脚或公告公布的联系方式联系运营者；

## 七、未成年人

本站不面向 14 周岁以下未成年人提供注册服务。存档内容来源于洛谷公开页面，若未成年人认为其公开内容不应被展示，可依[数据移除政策](/policies/data-removal)申请停止展示，或由监护人代为联系运营者。

## 八、政策更新

本协议可能不定期修订。重大变更将在站内公告或本页显著位置提示。继续使用本站即表示接受修订后的协议。
