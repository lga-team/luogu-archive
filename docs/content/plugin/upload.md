# 插件上传须知

面向想在插件广场**发布、更新或删除**插件的开发者。阅读本页前建议先浏览[插件使用须知](/plugin/usage)，了解用户侧看到的展示规则。

**前提**：一个完成邮箱验证的站内账号（[注册](/quick-start#五、注册账号-可选-但推荐)）。若插件对应的洛谷文章是你写的，**务必绑定洛谷账号**，否则之后无法认领插件（见[第七节](#七、认领插件)）。

## 一、基本规则

1. **一篇文章 = 一个插件**。插件以你在洛谷发布的介绍文章为「主页」，用文章 ID 关联；
2. **代码版本不可变**。发布后的版本代码不能修改；任何改动（包括修错字）都以**新版本**形式提交；
3. **所有发布 / 更新 / 删除都要经管理组人工审核**，一般**3 日内**处理完毕，请耐心等待；
4. 提交即表示你**确认代码和请求说明真实、完整**；
5. 插件代码版权归上传者所有，但你必须有权分发它（自己写的或已获授权）。

## 二、发布流程

1. 在洛谷写一篇**公开的**插件介绍文章（安装方法、功能说明、更新日志都建议写上）；
2. 记下文章 ID：文章地址 `https://www.luogu.com.cn/article/xxxxxx` 末尾那段即是（1–16 位字母数字，例如 `jbekb3o8`）；
3. 打开「插件广场 → 提交插件」，填入文章 ID，系统会自动读出文章标题供核对；
4. 填写插件信息表单（字段说明见[第三节](#三、表单字段说明)）并提交**发布申请**；
5. 管理组审核（一般 3 日内）：通过即上架；被打回则在「我的插件 → 申请记录」里看审核意见，修改后重新提交；
6. 上架后你可以在「我的插件」管理自己的插件、查看申请记录。

## 三、表单字段说明

| 字段 | 限制 | 建议 |
| --- | --- | --- |
| 简介 | ≤ 50 字 | 一句话说清插件做什么 |
| 版本号 | 1–64 字符 | 建议语义化，如 `1.0.0` |
| 代码 | ≤ 5 MiB | 提交**最终发布**的完整代码，发布后不可改 |
| 下载文件名 | 1–128 字符 | 用户脚本惯例用 `xxx.user.js`；不能含路径分隔符和 `\ / : * ? " < > |` 等字符 |
| 功能标签 | ≤ 20 个 | 只能选启用中的标签，别堆无关标签 |
| 运行方式 | 用户脚本 / 浏览器扩展 / 书签脚本 / 其他 | 必须与实际形态一致 |
| 支持设备 | 桌面 / 移动，至少选一项 | 移动端请实际测过再勾 |
| 最后验证日期 | 日期 | 你最近一次在洛谷实际验证插件可用的日期 |
| 请求等级 | 0–3 滑杆 | 判定标准见[第四节](#四、请求等级怎么定) |
| 请求说明 | 1–20000 字，支持 Markdown | **必填**，见下文 |

**请求说明**是审核的重点，请如实、完整地描述。清单要覆盖**所有出站请求**（洛谷 + 第三方）——对洛谷的请求决定请求等级，第三方请求不计级但同样逐条列明：

- 会请求**哪些接口 / 域名**（列清单）；
- 以**什么方式、什么频率**刷新或并发；
- 是否读取 **Cookie、Token、localStorage** 等登录态或本地数据，读了之后做什么、**是否上传**；
- 是否修改页面、注入样式、拦截或改写请求。

::: warning 请求说明不是可选项
任何等级都必须写清请求对象与数据流向。报「无请求」但对洛谷发请求、或第三方请求未申报，会被打回；上架后发现虚报会被下架。
:::

## 四、请求等级怎么定

等级**只计算对洛谷的请求**（`*.luogu.com.cn` / `luogu.com.cn`，含洛谷 CDN）的**频率**。对第三方的请求不计级，但**必须**写进请求说明——数据外传、隐私行为等安全问题由请求说明和审核把关。

### 触发分类

判定线：**是否用户明确允许了这次访问**。

| 分类 | 范围 |
| --- | --- |
| 自动请求 | 页面加载触发、定时器 / 轮询、后台缓存刷新、输入触发的查询——凡不是用户明确同意的请求 |
| 手动请求 | 仅指「点击以获取……」这类**明确发起网络操作的按钮**触发的请求 |

### 频率档

**0 级（无请求）**：不对洛谷发起任何请求。

1–3 级按下表判定，**就高不就低**，同时命中多档取最高：

| 级 | 自动请求 | 手动请求 | 任意两发间隔 |
| --- | --- | --- | --- |
| 少请求（1） | ≤ 1 次/h | ≤ 1 次/10min | ≥ 10s |
| 中等请求（2） | > 1 次/h | > 1 次/10min | < 10s |
| 较多请求（3） | > 1 次/10min | > 1 次/min | < 5s |

### 估算口径

1. **按 HTTP 请求数计**：一次触发发出 3 个请求算 3 发；同一触发并发发出的请求，间隔按 0 计。
2. **小突发豁免**：单次触发 ≤ 5 发、间隔 ≥ 1s 的连发，**不进冷却档位**（间隔条件不判这波），但发数照常计入频率。
3. **频率按摊销口径**：折算到单位时间的**平均速率**，按正常使用水平估算，不按最坏情况（狂点按钮不计）。例如一个 5000 粉的用户偶尔点一次「获取粉丝列表」（250 发），摊下来约 3 次/10min。
4. **自动请求按浏览画像折算**：每 3 分钟 1 个页面（≈ 20 页/时）。例如每次页面加载发 1 个请求 = 20 次/h = 3.3 次/10min，判 3 级；仅在特定页面触发的，按该类页面的典型访问频率折算。
5. 多触发通道并存时，各通道分别判完取最高。

### 判级示例

| 请求模式 | 判级 |
| --- | --- |
| 每次页面加载拉 1 个接口 | 3（自动 ≈ 20 次/h） |
| 页面加载扫描页面上全部用户名、缺缓存逐个拉接口 | 3（瞬发数十，间隔 ≈ 0） |
| 搜索框输入即查（打字每隔几个字一发） | 3（间隔 < 5s） |
| 明确按钮一次爬 ⌈N/20⌉ 页、每页间隔 1s | 3（> 5 发出豁免、间隔 < 5s）；限速到 5s 判 2，限速到 10s 判 1 |
| 明确按钮一次 3~5 发、间隔 1s、结果长期缓存 | 1（小突发豁免，摊销后日总量个位数） |
| 每 3 天同步一次题库文件 | 1 |

::: tip 红牌会随版本摘掉
3 级的红色标识描述的是**对洛谷请求频繁**，不等于「危险」。修改限速或触发方式后重新提交版本，等级会重新判定。
:::

## 五、更新版本

1. 在「我的插件」或插件详情页发起**更新申请**，填新版本号并提交新代码快照（其余字段按需修正，尤其是请求说明和最后验证日期）；
2. 更新申请同样需审核，一般 3 日内；
3. 旧版本永久保留，用户可在详情页切换查看、下载历史版本；
4. 功能性改动建议递增版本号（`1.0.0 → 1.1.0`），纯修复递增末位。

::: tip 为什么要小改动也走审核
插件广场承诺「页面上下载到的每一个版本都经过审核」，所以没有「免审核热修」通道。请预留审核时间。
:::

## 六、删除与下架

- **主动删除**：提交**删除申请**，审核通过后插件停止展示（历史版本仍可能为审核 / 争议留存）；
- **被动下架**：插件被举报查实违规，或管理组发现与申报不符，会被直接下架并通知；
- 下架后如需恢复，联系管理组说明整改情况。

## 七、认领插件

**场景**：插件对应的洛谷文章是你写的，但插件不在你名下（例如别人抢先提交了发布申请，或你换了站内账号）。

**条件**：站内账号已绑定洛谷账号，且绑定的 UID **等于该文章的作者 UID**。

**流程**：

1. [绑定洛谷账号](/quick-start#五、注册账号-可选-但推荐)（用你的洛谷账号完成剪贴板验证）；
2. 在插件详情页点「认领」，**即时生效**，插件转入你的站内账号名下；
3. 认领会**撤销其他人待审的相关申请**，并向对方发送通知邮件；
4. 认领操作每小时限 5 次。

认领只改变插件归属，不改变任何已发布版本的内容。

## 八、审核与常见打回情形

审核一般**3 日内**完成，结果在「我的插件 → 申请记录」查看。常见打回情形：

1. **请求等级虚报**（含报 0 级却对洛谷发请求、第三方请求未写进说明）、请求说明缺失或语焉不详；
2. **代码与描述不符**：功能对不上介绍、说明里的行为代码里没有（或反之）；
3. **代码无法运行**：语法错误、依赖缺失、复制即报错；
4. **危险或恶意行为**：窃取 Cookie / 密码 / 隐私并外传、静默下载执行、篡改其他网站内容等——这类不仅打回，还会处理上传者；
5. **侵权**：盗用他人插件代码、文章内容，或分发无权分发的代码；
6. **违法违规内容**：代码或介绍含色情、赌博、诈骗、恶意攻击等；
7. **灌水或重复提交**：同一插件反复提交无变化的版本、纯占位内容；
8. **格式不规范**：文件名不安全、版本号混乱、标签堆砌、简介与内容无关。

打回后可修改**重新提交**，不限次数；对判定有异议可通过页脚 / 公告联系方式申诉。

## 九、频率限制与违规处理

| 操作 | 限制 |
| --- | --- |
| 发布 / 更新 / 删除申请 | 每人每小时 10 次（同 IP 每小时 20 次） |
| 认领 | 每人每小时 5 次 |
| 举报（作为举报方） | 每人每小时 5 次 |

违反本须知的处理包括：打回申请、下架插件、撤销认领、封禁插件提交权限，直至封禁账号；涉嫌违法的配合主管机关处理。责任条款见[免责声明](/policies/disclaimer)第四条。
