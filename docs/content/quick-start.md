# 快速上手

第一次来洛谷档案馆？这一页带你从「找到内容」到「用起来」，几分钟就够了。

如果你还不确定本站是做什么的，先看[欢迎页](/)；使用本站前请阅读[免责声明](/policies/disclaimer)。

## 一、本站能做什么

洛谷档案馆是一个**第三方非官方**的存档站，长期保存洛谷社区的公开内容，并追踪它们随时间的变化：

| 能力 | 说明 |
| --- | --- |
| 文章 / 剪贴板存档 | 全文保存，**逐版本保留编辑历史** |
| 陶片放逐存档 | 社区治理公开记录的时间线 |
| 用户历史追踪 | 用户名、简介、粉丝数、Elo / 咕值等变化历史 |
| 插件广场 | 浏览、下载经审核的洛谷相关插件，也可上传自己的插件 |
| 题解格式修正 | 本地规则修正 + AI 润色，帮你把题解排版改规范 |

::: info 本站与洛谷官方无关
存档内容版权归原作者所有。如果你是作者且不希望内容被存档，见[第七节](#七、删除我的内容)。
:::

## 二、找到想看的内容

- **首页搜索框**：直接粘贴洛谷链接（例如 `https://www.luogu.com.cn/article/xxxxxx`），回车即可跳到对应存档页。
- **侧边栏**：浏览各板块的收录列表（文章、陶片放逐、用户、插件广场、站务公告等）。
- **站内搜索**：文档站与站内均支持关键词检索（文档站搜索框在页面顶部）。

如果搜不到你想看的内容，说明本站还没收录它——用「保存」按钮补上，见下一节。

## 三、保存一篇内容

页面顶部的**「保存」/「更新」按钮**是本站的核心交互：

1. 打开内容的存档页（或粘贴链接跳转过去）；
2. 点击页面顶部的「保存」按钮（已收录的内容按钮为「更新」）；
3. 如弹出人机验证，按提示完成验证；
4. 等待提示完成，稍后刷新页面即可看到最新存档。

**关于限流与排队，先了解这几件事：**

| 规则 | 数值 | 说明 |
| --- | --- | --- |
| 频率上限 | 每分钟每 IP 20 次 | 超出后提示稍后再试 |
| 人机验证 | 1 分钟内 3 次，或 10 分钟内 10 次 | 触发后 10 分钟内的保存都需要先验证 |
| 重复请求合并 | 60 秒内同一目标 | 不会重复排队，直接返回已有的任务 |

::: warning 保存是异步的
点击保存只表示「已加入抓取队列」。抓取按优先级调度，并受源站限速影响，**不承诺完成时效**。提示完成后建议刷新页面查看；若内容仍显示旧版本，可稍后再试。
:::

::: tip 小技巧
保存按钮同样适用于「收藏的冷门内容」——抓的人越少，自动巡检越难覆盖到，手动点一下最可靠。
:::

## 四、查看历史变化

本站的特色是**版本与时间线**，不只是最新快照：

- **文章 / 剪贴板**：进入详情页的「历史版本」，可以看到每次编辑的时间线，逐版本查看内容。
- **用户主页**：用户名（含颜色、称号）、个人介绍的历史版本，以及粉丝数、Elo、咕值等数值的变化曲线。
- **陶片放逐**：按时间排列的处罚记录。

::: info 历史从首次收录开始
版本记录只能从本站**首次抓取**该内容时开始，更早的变化无法补回。数值曲线同理，只有收录之后的观测点。
:::

## 五、注册账号（可选，但推荐）

不注册也能浏览和保存内容。注册一个站内账号后可以：

- **关注洛谷用户**，在「我的关注」里集中查看；
- **绑定洛谷账号**，用于插件认领与删除申请直通（见下文）；
- **使用 AI 题解修正**（本地修正不需要登录）；
- **上传与管理插件**；
- 提交删除 / 侵权申请时自动带入联系方式。

**注册步骤：**

1. 侧边栏点「注册」，填邮箱、昵称（1–16 字）和密码（至少 8 位，同时包含字母和数字）；
2. 查收验证邮件，**24 小时内**点击邮件中的链接完成验证（没收到先看垃圾箱；同一邮箱 60 秒后可重发）；
3. 回到「登录」页登录即可。

::: warning 验证后才能登录
未完成邮箱验证的账号无法登录。验证链接过期后请在登录页用「重发验证邮件」重新获取。
:::

**绑定洛谷账号**（在设置页操作）：

1. 点「获取验证文本」，得到一段带验证码的验证文本（10 分钟内有效）；
2. 去洛谷新建一个**公开剪贴板**，把验证文本完整粘贴进去并保存；
3. 回到本站，填入该剪贴板的 ID，点「验证绑定」。

绑定成功后，你的站内账号就与该洛谷账号（以其 UID 为准）一一对应。**作者本人通过绑定账号提交的删除申请即时生效**，无需人工审核，详见[数据移除政策](/policies/data-removal)。

## 六、其他实用功能

- **题解格式修正**（「题解修正」页）：粘贴题解 Markdown，本地规则引擎会修正标题、列表、引号、中英文空格、未闭合公式等常见格式问题；AI 润色需要登录，每人每小时 5 次，输出请人工核对后再采用，修正结果会自动附加 AI 参与声明。
- **洛谷主题导入**（「设置」页）：填入洛谷主题 ID 即可预览并应用你在洛谷配置的自定义主题配色。

## 七、删除我的内容

本站支持删除 / 侵权申请，分两种方式：

- **作者本人**：注册站内账号并[绑定洛谷账号](#五、注册账号-可选-但推荐)后，在「侵权投诉 / 内容删除」页提交，系统自动核验所有权并**即时停止展示**；
- **其他人**（侵权投诉等）：同一页面提交申请与证据，转人工审核。

完整规则、适用范围与不支持的情形见[数据移除政策](/policies/data-removal)。
