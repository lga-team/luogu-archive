# 洛谷档案馆帮助中心

欢迎！

这里是 [洛谷档案馆](https://www.luogu.ac.cn) 的帮助中心。洛谷档案馆是一个**非洛谷官方**的第三方开源存档站，长期保存洛谷社区的公开内容，并提供历史版本追踪、插件广场、题解格式修正等功能。

## 你想做什么？

| --- | --- |
| 第一次使用，快速了解 | [快速上手](/quick-start) |

| 投诉侵权、了解责任边界 | [免责声明](/policies/disclaimer) · [数据移除政策](/policies/data-removal) |
| 了解数据如何被收集与使用 | [隐私协议](/policies/privacy) |

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 文章 / 剪贴板保存 | 全文存档，逐版本保留编辑历史 |
| 陶片放逐保存 | 社区治理公开记录长期存档 |
| 用户历史保存 | 用户名、简介、粉丝数、Elo / 咕值等变化历史 |
| 犇犇保存 | 全站犇犇长期存档 |
| 讨论区保存 | 目前仅支持非题目版块 |
| 插件广场 | 浏览、下载、上传浏览器插件 |
| 题解格式修正 | 本地格式修正 + AI 润色（AI 需登录） |

曾上线后已下架：比赛历史与等级分预估、题目保存——因 [洛谷官方要求](https://luogu.ac.cn/discuss/1368593) 暂时移除。
