# 插件使用须知

插件广场汇集了第三方开发者上传、经管理组人工审核发布的洛谷相关插件（用户脚本、浏览器扩展等）。安装任何插件前，请先读完这一页。

::: danger 插件代码风险自担
插件由第三方开发者编写，**管理组审核不构成安全担保**。安装与使用插件前请自行阅读代码与权限说明；因使用插件造成的任何损失（账号、数据、设备损害等），本站不承担责任，详见[免责声明](/policies/disclaimer)第四条。
:::

## 一、插件是什么

- 插件广场里的每个插件对应洛谷上的一篇**介绍文章**，代码以**不可变版本**的形式存档在本站：发布后的版本代码不会再变，更新会以新版本号追加。
- 代码可以在线查看（预览）、复制或下载，页面会显示上传者与管理组各自的**请求说明**。
- 插件按**运行方式**分为四类：

| 运行方式 | 说明 | 安装前提 |
| --- | --- | --- |
| 用户脚本 | 在网页里注入 JS 的脚本 | 需要 Tampermonkey / Violentmonkey 之类的脚本管理器 |
| 浏览器扩展 | 浏览器插件 / 扩展 | 按扩展的方式加载安装 |
| 书签脚本 | 一段存在书签里的 JS | 拖到浏览器书签栏，点一下运行 |
| 其他 | 以上都不是 | 以插件介绍说明为准 |

- 插件标注了**支持设备**（桌面 / 移动），至少支持一种；移动浏览器对脚本管理器支持有限，装之前先确认。

## 二、权限等级怎么看

每个插件都有一个 0–3 的**请求等级**，描述它**对洛谷发起请求的频繁程度**（对第三方的请求不计级，但都写在请求说明里）：

| 等级 | 含义 | 你要注意什么 |
| --- | --- | --- |
| 无请求（0） | 不对洛谷发起任何请求 | 洛谷侧最干净；第三方请求看说明 |
| 少请求（1） | 对洛谷非常克制：自动请求 ≤ 1 次/时、明确按钮 ≤ 1 次/10 分钟、任意两发间隔 ≥ 10 秒 | 一般较安全，仍建议扫一眼代码 |
| 中等请求（2） | 比 1 频繁但不密集：自动 > 1 次/时、按钮 > 1 次/10 分钟，或两发间隔 < 10 秒 | 看清请求说明里发给了谁、发了什么 |
| 较多请求（3） | 请求频繁或突发密集：自动 > 1 次/10 分钟、按钮 > 1 次/分钟，或两发间隔 < 5 秒，页面上显示**红色标识** | **务必读代码和请求说明后再安装** |

几个要点（完整判定标准见[上传须知 · 请求等级怎么定](/plugin/upload#四、请求等级怎么定)）：

- **「自动」包括页面加载触发、定时轮询、输入即查**；只有「点击以获取……」这类明确按钮才算「手动」；
- 一次触发的并发请求、批量连发都如实计入；≤ 5 发、间隔 ≥ 1 秒的小突发不按间隔定级；
- 频率按正常使用摊销估算，不是最坏情况（狂点按钮不算）。

::: tip 等级只描述「对洛谷的请求频率」
3 级的红色标识表示**对洛谷请求频繁**，不等于「危险」；反过来，等级低也不代表代码无害——等级不衡量第三方上传、页面篡改等行为，这些只能靠**读代码和请求说明**判断。最可靠的做法始终是读代码。
:::

详情页的「分析」标签页里有两份说明：

- **上传者请求分析**：作者申报的请求行为描述（会请求哪些接口、什么方式、什么频率、是否读取 Cookie / Token / localStorage 并上传数据等）；
- **管理组请求分析**：管理组复核后的补充说明。**两者不一致时以管理组结论为准**（管理组可能调整请求等级）。

## 三、怎么找插件

打开「插件广场」，左侧筛选栏支持：

- **功能标签**：按用途筛选；
- **请求等级 / 运行方式 / 支持设备**：按上文两节的维度缩小范围；
- **最近更新**：只看近期仍在维护的插件。

排序支持：综合、最新、使用最多、最近验证。点插件标题进入详情页。

## 四、安装

1. 在详情页顶部的「代码版本」下拉框选择要安装的版本（默认最新）；
2. 点**「下载文件」**拿到插件代码文件（文件名即下载文件名，如 `plugin.user.js`）；
3. 按运行方式安装：

- **用户脚本**：把 `.user.js` 文件拖入脚本管理器，或在脚本管理器里导入；
- **浏览器扩展**：按浏览器的扩展加载方式安装（具体以介绍说明为准）；
- **书签脚本**：新建书签，把代码粘贴进网址栏，或按说明拖拽到书签栏；
- **其他**：按插件介绍说明操作。

4. 站内点击「下载文件」时会弹出**安装确认**，展示版本号、文件名与请求说明，请核对后再下载。

::: warning 代码复制限制
完整代码超过 100 KiB 时，页面不支持一键复制，只能下载文件；在线预览最多显示 1000 行 / 50 KB，完整代码请以下载文件为准。
:::

## 五、更新与卸载

- **更新**：作者发布新版本后，回到详情页下载新版本，用同样方式覆盖安装即可。旧版本会保留在「代码版本」列表里，可随时切换下载。
- **最后验证日期**：上传者声明的最近一次实际验证插件可用的日期。日期久远不代表失效，但意味着兼容性没人担保——洛谷改版后老插件可能悄悄坏掉。
- **卸载**：在脚本管理器里删除脚本 / 在浏览器扩展管理页移除扩展 / 删除对应书签。插件保存在浏览器本地的数据（如脚本管理器的存储）需要在其设置里单独清理。

## 六、遇到问题怎么办

发现插件有问题，请在详情页的**「举报插件」**表单提交（每小时限 5 次，说明至少 10 个字）：

| 举报类型 | 适用情形 |
| --- | --- |
| 危险请求 | 插件发起与功能无关的请求、超出请求说明范围的联网行为 |
| 恶意代码 | 窃取 Cookie / 密码 / 隐私数据，静默下载执行等 |
| 功能损坏 | 插件不能正常使用、报错、与描述不符 |
| 版权问题 | 盗用他人代码或内容 |
| 误导 | 说明、等级、截图与实际行为不符 |
| 其他 | 以上都不合适时 |

::: danger 怀疑插件窃取账号？
立即停用插件、在安全设备上修改洛谷与本站密码、检查异常登录，然后举报并联系运营者（页脚 / 公告有联系方式）。
:::

举报后由管理组人工处理；属实的会要求作者整改或下架插件，恶意 / 危险插件会被直接移除并处理上传者。

## 七、下载数与复制数

插件卡片上的下载数、复制数按**访客去重**统计：同一访客同一天内多次下载或复制只计一次。它们反映大致的使用热度，不代表安装量或活跃用户数。
