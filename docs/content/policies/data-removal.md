# 数据移除政策

**生效日期：2026 年 10 月 13 日**

洛谷档案馆尊重内容作者的意愿与社区规则。本政策说明如何申请移除（停止展示）站内数据，以及各类申请的处理规则。

## 一、总览

所有数据移除申请分为**自动审核**与**人工审核**两种方式，互不混用：

| 方式 | 适用对象 | 处理方式 | 时效 |
| --- | --- | --- | --- |
| **自动审核** | **个人内容**——内容作者本人申请移除自己的内容 | 系统自动核验所有权后**自动批准**，无需人工介入 | 提交即生效 |
| **人工审核** | **涉嫌违规内容**——内容涉嫌违反法律法规或社区规则 | 提交申请与证据，由管理员人工裁决 | 尽快处理 |

**核心规则：**

1. **所有个人内容的移除，请一律使用自动审核**：您是作者本人（通过绑定洛谷账号证明）即可自助完成，系统自动通过，不占用人工审核资源。
2. **只有涉嫌违反规则的内容才进入人工审核**：例如侵权、违法违规、泄露他人隐私、攻击他人等情形。
3. **打回规则：个人内容且不涉嫌任何违规的移除申请，提交人工审核将被一律打回。** 例如：非作者仅因个人好恶、观感、希望"清理"他人内容而提出的申请，不构成移除理由；作者本人也无需（也不应）走人工方式，直接使用自动审核即可。

## 二、名词说明

- **个人内容**：由洛谷用户创作、能明确归属到作者本人的内容，包括：**用户主页**、**文章**、**剪贴板**、**犇犇**、**讨论区帖子**。
- **涉嫌违规内容**：涉嫌违反中华人民共和国法律法规、侵犯他人合法权益（著作权、隐私权、名誉权等）、违反洛谷或本站社区规则的内容。
- **软隐藏**：本站的移除方式（详见第六节），即"停止公开展示 + 阻止再次抓取"，而非从数据库物理抹除。

## 三、自动审核

### 1. 适用条件

- 申请对象是**个人内容**（用户主页 / 文章 / 剪贴板 / 犇犇 / 讨论）；
- 您是该内容的**作者本人**：注册本站账号并**绑定洛谷账号**（在 `/takedown` 页面或"账号绑定"处按指引完成——将一次性挑战文本放入您的公开洛谷剪贴板，系统核验后绑定您的洛谷 UID）。

### 2. 处理流程

1. **地址探测**：粘贴内容的完整链接（如 `https://www.luogu.com.cn/article/xxxx`），系统自动识别内容类型（10 分钟内有效）；
2. **所有权核验**：系统比对您绑定的洛谷 UID 与内容作者 UID；
3. **自动批准**：匹配成功即自动通过（理由自动记为"绑定账号本人申请隐藏"），**无需填写理由、无需人工审核**；
4. **立即生效**：软隐藏即时执行，并向您的邮箱发送处理结果通知（如已留邮箱）。

### 3. 特别说明

- **本人申请不受"源站可访问性"限制**：即使内容在洛谷上仍公开可见，您也可以随时申请隐藏本站的存档副本；
- **主页级联**：申请移除**用户主页**时，该用户名下全部存档内容（文章、剪贴板、犇犇、讨论等）**一并级联隐藏**；
- 同一内容已有待处理申请时，不能重复提交；
- 若目标内容此前已被隐藏，探测阶段即提示"该内容已经停止公开展示"。

## 四、人工审核

### 1. 适用条件

仅当内容**涉嫌违反规则**时方可使用本方式，典型情形：

- 侵犯他人著作权（转载/抄袭且权利人主张）；
- 泄露他人隐私（真实姓名、联系方式、单位等非公开信息）；
- 违法违规内容（色情、赌博、暴恐、诈骗等）；
- 人身攻击、诽谤、恶意挂人；
- 其他违反洛谷社区规范或本站规则的内容。

### 2. 提交要求

1. **目标内容的完整链接**（系统自动识别类型）；
2. **申请理由**：不少于 **10 个字**，须说明涉嫌违规的具体情形；
3. **联系方式**：邮箱（登录用户可自动填入注册邮箱），用于接收裁决结果；
4. **建议附上证据**（截图、原始链接、权属证明等）。证据越充分，相对处理会越快。

### 3. 受理前提

提交前系统会进行**地址探测**（重新抓取源站状态，结果 10 分钟内有效）：

- **目标内容在源站（洛谷）仍可公开访问，且您不是作者本人的，申请不予受理**，系统直接拒绝提交。请先通过洛谷官方渠道处理源站内容，或改走作者本人的自动审核方式；
- 目标内容在源站已删除/不可访问的，方可提交进入人工审核；
- 同一内容存在待处理申请的，不能重复提交。

### 4. 管理员裁决

管理员收到申请后核查内容与证据，作出以下裁决之一：

- **批准**：执行软隐藏，并向申请人邮箱发送结果通知；
- **打回**：不予移除，并附打回说明，向申请人邮箱发送结果通知。

### 5. 打回情形

出现以下任一情形，人工审核申请将被打回：

1. **申请对象是个人内容且不涉嫌任何违规**（无论内容在源站是否仍可访问）——例如仅因"不喜欢""希望删除他人历史记录""觉得内容过时"等非违规理由；作者本人请改走**自动审核方式**；
2. 理由少于 10 个字、含糊其辞、与内容无关或无法核实；
3. 提供虚假材料或恶意申请；
4. 内容为陶片放逐记录、题目信息等**暂不支持在线移除申请**的类型（见第八节）；
5. 重复申请已被裁决过且无新证据的内容（含恢复后再申请）。

## 五、审核方式速查

| 情形 | 方式 | 结果 |
| --- | --- | --- |
| 本人申请隐藏自己的文章/剪贴板/犇犇/讨论 | 自动审核 | 自动通过，即时生效 |
| 本人申请隐藏自己的用户主页（级联全部内容） | 自动审核 | 自动通过，即时生效 |
| 第三方举报内容涉嫌侵权/违法/违规 | 人工审核 | 批准隐藏或打回 |
| 第三方申请移除无违规的个人内容 | 人工审核 | **打回** |
| 第三方申请移除源站仍公开的非本人内容 | 不予受理 | 自动初审拒绝提交 |
| 本人走人工方式申请无违规内容移除 | 人工审核 | **打回**（提示改走自动方式） |

## 六、移除效果

申请批准后（无论自动或人工），本站执行**软隐藏**：

1. **停止公开展示**：所有公开页面（详情、列表、用户页、时间线、SVG 卡片、插件页等）不再展示该内容；直接访问被隐藏内容的接口返回 `451`（`该内容已根据删除申请停止公开展示。`）；
2. **阻止再次抓取**：爬虫在抓取前与抓取后均检查隐藏名单，隐藏生效期间**不会**重新抓取或重新收录该内容及其新版本；隐藏用户主页时，该用户名下的内容同样不会被再次抓取；
3. **级联规则**：单条内容隐藏只影响该条目；用户主页隐藏级联该用户全部内容；
4. **数据留存说明**：软隐藏后，**已抓取的档案数据与历史版本仍保存于本站数据库中**，仅停止对外展示与再次抓取。这是为了保留社区历史档案并支持可能的恢复操作；如您有彻底删除底层数据的特殊需求（如涉及法律强制要求），请通过页脚 / 公告联系方式联系运营者个案处理。个别类型的管理操作（如犇犇的管理员删除）会物理删除对应记录，但通常情况下移除 = 软隐藏。

### 用户名违规隐藏

与上述方式相互独立的**用户名违规级联隐藏**：

- **触发**：陶片放逐理由命中违规关键词、用户名命中系统保留格式（如 `_user_\d+`）、或管理员手动判定；
- **效果**：该用户名**在触发时刻之前的所有历史名**全部永久隐藏（展示为 `UID xxx` 并剥离颜色、徽章、评级），此后改用合规新名可正常展示；
- **不可逆**：即使后来改回合规用户名、即使陶片撤销，已隐藏的历史名**不恢复**；
- 该机制为自动执行，不接受针对"历史名隐藏"的单独申诉；相关申诉请走人工说明渠道。

## 七、恢复

1. **误隐藏可恢复**：管理员可对已批准的隐藏执行恢复，内容重新公开展示，并恢复允许抓取；
2. 作者本人发现误操作，可联系运营者申请恢复；
3. 恢复后的内容如需再次隐藏，请重新提交申请（同一目标可再次批准，复用同一条隐藏记录）；
4. **用户名违规级联隐藏不在恢复范围内**（见上）。

## 八、暂不支持在线移除的类型

以下内容**暂不开放**自助移除申请：

- **陶片放逐记录**：作为社区治理的公开记录存档，不接受以"个人内容"名义的移除申请。若记录本身涉嫌违法/侵权，可联系运营者个案处理；
- **题目元信息**（编号、标题、难度、标签、题解开放状态）：来自洛谷公开题库，不针对个人，一般不接受移除申请；
- **比赛相关数据**（如启用）：公开赛事信息，一般不接受移除申请。

## 九、频率限制与防滥用

为防止滥用，移除申请接口设有频率限制：

- 地址探测：每 IP 每小时最多 **20** 次；
- 提交申请：每 IP 每小时最多 **5** 次；
- 同一内容同时只能有一个待处理申请；
- 恶意、批量、虚假申请可能被限流、驳回并记录。

## 十、通知

- **自动审核**：通过后即刻向申请邮箱（如已填写）发送结果通知；管理员同步收到知会邮件；
- **人工审核**：提交后管理员收到通知邮件；裁决（批准 / 打回）后向申请邮箱发送结果与说明；
- 未留邮箱的申请，结果以站内状态为准，恕不另行通知。

## 十一、申诉与联系

- 对人工审核裁决有异议、有新证据的，可通过页脚 / 公告公布的联系方式联系运营者复核；
- 涉及法律程序（律师函、司法机关调取等），请通过同一渠道联系，我们将依法配合。
